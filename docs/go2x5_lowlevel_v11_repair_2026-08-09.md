# Go2-X5 low-level v11 行为诊断与重训方案

日期：2026-08-09

## 结论

v10 的 `model_29000.pt` 和 `model_29200.pt` **不是满足 high-level 要求的
底层策略**。它们可以安全站立并在随机 6D 目标下维持有限的 EE 误差，但
固定命令评测暴露了不可接受的方向不对称、低摆脚和接触滑移。因此本轮不
启动 high-level teacher，而是从随机初始化启动一次 v11 low-level 正式长训。

## 已执行的确定性评测

两份 checkpoint 均在同一物理 GPU、同一确定性配置下执行：

- 站立、前进、后退、左转、右转固定命令；
- 随机完整 6D EE 目标协同 rollout；
- reset、碰撞、非有限值、动作饱和、关节力矩、EE 位置/姿态误差、速度
  跟踪、身体高度和俯仰相关性统计；
- 另对 iteration 2800、6000、10000、15000、20000、25000 做同一固定
  命令里程碑扫描，用来区分实现错误与训练退化。

关键结果如下：

| 检查 | model 29000 | model 29200 | 要求 | 结论 |
|---|---:|---:|---:|---|
| 前进平均 `vx` | 0.0994 | 0.1046 | 目标 0.10 | 通过 |
| 后退平均 `vx` | -0.0939 | -0.0908 | 目标 -0.10 | 速度通过，但前脚主要滑移 |
| 左转平均 yaw rate | 0.0472 | 0.0345 | 目标 0.15 | 失败 |
| 右转平均 yaw rate | -0.1392 | -0.1509 | 目标 -0.15 | 通过 |
| 前进四足平均离地高度 | 0.0268--0.0333 m | 0.0266--0.0340 m | 至少 0.04 m | 失败 |
| 后退前足 airborne 比例 | 2.8% / 4.2% | 1.0% / 2.0% | 必须有有效摆动 | 失败 |
| 随机 6D EE 位置误差 | 同量级 | 0.0066 m | 有限且稳定 | 通过 |
| 随机 6D EE 姿态误差 | 同量级 | 0.0265 rad | 有限且稳定 | 通过 |
| 动作饱和比例 | 约 12.95% | 约 12.40% | 不超过 5% | 失败 |

里程碑扫描表明，机械系统并非无法左转：`model_6000` 左转约 0.109 rad/s，
之后却逐渐下降到 0.035 rad/s；同时右转持续改善。命令采样器的正负 yaw
比例已通过 30%--70% 的平衡检查。因此根因不是关节 permutation 或命令
符号写反，而是训练目标的竞争和局部最优。

## 根因

1. v10 在 iteration 3000 就启动机械臂目标运动并混入 whole-body
   advantage，但 `model_2800` 尚未学会移动。locomotion 基础形成前就引入
   EE、姿态和俯身目标，过早产生梯度竞争。
2. 原 `feet_height` 依赖 gait clock 的 `desired_contact_states`，而当前
   简化合同明确关闭 gait clock。直接启用旧实现不能给实际摆动脚提供有效
   信号，所以低净空滑行长期存在。
3. 原地转向只占 10% episode，yaw tracking 权重仅为线速度的四分之一；
   已观察到的单方向退化没有足够采样和梯度纠正。
4. v10 没有动作幅值尾部约束，actor 可以用饱和 PD target 换取速度；随机
   协同评测中的动作饱和比例达到约 12%--13%。

## v11 最小修复

- 保持平地、12D 腿动作、网络、PPO、PD `40/1` 和 action scale
  `0.125/0.25/0.25` 不变。
- locomotion-only 和静止机械臂阶段延长到 iteration 8000；8000--12000
  线性混入 whole-body advantage。
- 命令人群改为 10% 站立、40% 双向直行、20% 双向原地转向、30% 一般
  `vx/vy/yaw`。
- yaw tracking 权重从 0.5 提高到 1.0，仍低于线速度权重 2.0。
- `feet_air_time` 从 1.0 提高到 2.0。
- 启用 phase-free `feet_height=1.0`：无 gait clock 时只根据实际过滤接触
  判定离地脚，对足心低于 0.05 m 的短缺取每足平均惩罚。它不规定 trot、
  walk 或任意腿间相位。
- 启用 `leg_action_l2_deadzone=-0.5`，只惩罚 `abs(action)>0.8` 的二次尾部；
  正常动作完全不受该项影响。

## 训练与后续准入

v11 应从随机初始化完整训练 45000 iteration，不从 v10 checkpoint 续训。
训练启动前必须通过 GPU readiness；训练中按固定命令评估 milestone。只有
候选 checkpoint 同时满足以下条件才可进入 high-level：

- 站立、前进、后退、左转、右转均通过方向和跟踪误差门禁；
- 四只脚均发生实际摆动，摆脚高度与接触滑移达标；
- 动作饱和比例不超过 5%；
- EE 位置/姿态、机身高度/俯仰协同有限且无 IK clamp 异常；
- 0 early reset、0 nonfinite，并通过 schema-v2 contract loader。

本次长训的启动状态、tmux 名称和输出目录记录在最终操作回报中。正式
checkpoint 产生并通过上述门禁前，不允许启动 high-level teacher 长训。
